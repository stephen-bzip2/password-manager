# Password Vault

my first c project lol

i made this while learning c and wanted to actually build something instead of just doing random exercises.

## what it can do

- create an account
- login with username and password
- checks if username and password are correct
- menu that keeps running until you exit
- saves the account in a file
- basic file handling

## what i learned from this project

- variables
- char arrays / strings
- scanf and printf
- if / else if / else
- while loops
- strcmp()
- files
- fopen()
- fprintf()
- fscanf()
- fclose()
- git and github
